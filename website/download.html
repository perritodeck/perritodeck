Download PerritoDeck

Version 0.1.0 · free and open source · no account needed

You need two things: PerritoDeck Host on your computer, and Perrito on your tablet or phone. The host does what your buttons ask, and the tablet shows them.

Not released yet. PerritoDeck is in early development, and the download links below start working on launch day. Until then, you can build it from the source code.

1. Install the host on your computer

The desktop app sits in your tray, pairs tablets, and lets you lay out your buttons.

Windows Your system

Windows 10 or 11, 64-bit. Installs just for you, no administrator needed.

Download installer (.exe)
  • MSI package for all users and managed PCs
  • winget package coming

Uses Microsoft Edge WebView2, which Windows 11 already has. The installer adds it on Windows 10 if it's missing.

macOS Your system

macOS 10.15 Catalina or newer. One app for Apple silicon and Intel Macs.

Download for Mac (.dmg)
  • Homebrew cask coming

To press keys for you, PerritoDeck asks for Accessibility access in System Settings → Privacy & Security.

Linux Your system

64-bit (x86_64), X11 or Wayland. The AppImage runs on most distributions.

Download AppImage
  • .deb for Debian, Ubuntu, Mint
  • .rpm for Fedora, openSUSE
  • Flathub and AUR coming

Needs WebKitGTK 4.1 (Ubuntu 22.04, Debian 12, Fedora 36 or newer). On Wayland, your desktop asks once per start to allow keyboard and mouse control.

System requirements

WindowsWindows 10 or 11, 64-bit, with WebView2 (installed automatically if missing)
macOSmacOS 10.15 or newer, Apple silicon or Intel
Linuxx86_64 with GTK 3 and WebKitGTK 4.1; a tray that supports AppIndicator/StatusNotifier (GNOME needs the AppIndicator extension). Wayland input uses the Remote Desktop portal (GNOME and KDE Plasma).
Tablet or phoneAndroid 5.1 (Fire OS 5) or newer, on the same Wi-Fi as the computer or connected by USB
Plugins (optional)The plugins that come with PerritoDeck (OBS, Proxmox, timers and more) need Python 3. Plugins written in JavaScript, and Stream Deck plugins, need Node.js 20 or newer. Without them, everything else works.
USB connection (optional)Android's adb tool (Android SDK Platform-Tools) on the computer

Getting Python 3 and Node.js

  • Windows: winget install Python.Python.3.13 and winget install OpenJS.NodeJS.LTS, or the installers from python.org and nodejs.org.
  • macOS: brew install python node, or the installers from python.org and nodejs.org.
  • Linux: Python 3 is usually there already; Node.js is in your package manager (nodejs).

First launch of an unsigned build

Until the apps are code-signed, your system warns you the first time you open them. That's expected for any app without a paid certificate, and you can check the file yourself first (below).

  • Windows: SmartScreen says "Windows protected your PC". Click More info, then Run anyway.
  • macOS: if macOS says the app can't be opened, open System Settings → Privacy & Security and click Open Anyway next to the PerritoDeck message.
  • Linux AppImage: make it executable first: chmod +x perritodeck-*.AppImage.
  • Android: allow your browser or file manager to install unknown apps when it asks.

Check your download

Each release comes with a file called SHA256SUMS that lists a SHA-256 checksum, a fingerprint of the exact bytes, for every file. If your file's checksum matches its line there, you got exactly what was built from the published source, with nothing changed or cut off along the way. Download SHA256SUMS into the same folder, then run:

Linux

sha256sum -c SHA256SUMS --ignore-missing

macOS

shasum -a 256 -c SHA256SUMS --ignore-missing

(If your shasum doesn't know --ignore-missing, run shasum -a 256 perritodeck-0.1.0-macos-universal.dmg and compare by eye.)

Windows (PowerShell)

Get-FileHash .\perritodeck-0.1.0-windows-x64-setup.exe -Algorithm SHA256

On Linux and macOS each file should say OK. On Windows, compare the long hash with the line for that file in SHA256SUMS (upper or lower case doesn't matter).

Every file is built from the tagged source by GitHub Actions, in public, and the build log shows the same checksums. When the Android app is signed, its certificate fingerprint will be published here too, so you can check it with apksigner verify --print-certs perrito-0.1.0.apk.

Command-line host

For servers, kiosks and scripting: the same host without a window, plus perritodeck-fakedeck, a test client that needs no tablet. It's in the release as perritodeck-host-0.1.0-linux-x86_64.tar.gz, -windows-x86_64.zip and -macos-universal.tar.gz. Run perritodeck-host --pair to pair a tablet.
