PerritoDeck turns an old Android tablet or phone into a Stream Deck–style control surface for your computer. Its keys press hotkeys, type text, control media and volume, open apps and websites, run commands, and show live values such as CPU use or the OBS scene. OBS Studio is built in, and 24 plugins come with it ([features](https://perritodeck.dev/features.html)). It's free and open source, with no account and no cloud.

This first release is for Windows, with Perrito on Android tablets and phones, Amazon Fire included. It's pre-alpha: expect rough edges and breaking changes.

## What you need

- **A Windows 10 or 11 PC, 64-bit.** PerritoDeck installs just for you, with no administrator needed. On Windows 10 the installer may download Microsoft Edge WebView2, so stay online while it runs.
- **An Android tablet or phone with Android 5.1 or newer,** Amazon Fire tablets included, on the same Wi-Fi as the computer. A USB cable works too, with USB debugging on and Android's `adb` tool on the computer ([how](https://perritodeck.dev/guide/getting-started.html#usb)).
- **Optional:** Python 3 for the plugins that come with PerritoDeck, and a current Node.js LTS for JavaScript and Stream Deck plugins ([how to get them](https://perritodeck.dev/download.html#requirements)).
- **Not in this release:** macOS, iPhone and iPad, Linux packages, and the command-line host. Linux and the command-line host [build from source](https://perritodeck.dev/download.html#source), but Linux hasn't been tried on a desktop with a tablet yet.

## Getting started

1. On the computer, run `perritodeck-0.1.0-windows-x64-setup.exe` (under Downloads below). It isn't signed yet, so SmartScreen says "Windows protected your PC": choose **More info**, then **Run anyway**.

2. The first time PerritoDeck starts, Windows Firewall asks whether it may use the network. Allow it on private networks, and check that Windows treats your home Wi-Fi as private: on a network Windows calls public, the prompt's default lets nothing in, and tablets connect only over USB ([help](https://perritodeck.dev/guide/troubleshooting.html#cable-only)).
3. On the tablet, download `perrito-0.1.0.apk` and open it. Android asks before it installs an app from outside an app store: allow it. On a Fire tablet, first allow apps from unknown sources in Settings → Security & Privacy.
4. The first time, PerritoDeck's window shows **Pair a tablet**. In Perrito, tap **Scan QR code** and point the camera at the code, or tap **Pair** next to your computer and type the 6-digit code.

Closing the window leaves PerritoDeck running in the tray. The [getting started guide](https://perritodeck.dev/guide/getting-started.html) has the details, USB included. To hear about new versions, tick **Tell me when a new version is out** in Settings; it's off until you do.

Perrito isn't on Google Play. [Obtainium](https://obtainium.imranr.dev/) can keep this APK updated from GitHub, and so will IzzyOnDroid, coming soon. F-Droid, also coming, signs its own copy, so moving to it means uninstalling this one first.

## Experimental

Experimental means it has only been tried against stand-ins for the real service or device, or with sample plugins, so it may not work with yours. If you try one, [tell us](https://github.com/perritodeck/perritodeck/issues/new/choose) how it went.

- **Plugins:** GitLab, HTTP requests, Philips Hue, Elgato Key Light, MQTT, Ollama, Proxmox VE, Spotify, TrueNAS, Twitch, Weather, Wake-on-LAN and "Is it up?" (uptime checks). They come with PerritoDeck, but the app's **Comes with PerritoDeck** list doesn't mark them; **Look online** and the [catalogue](https://perritodeck.dev/plugins/) do, and say what each was tested against.
- **Built in:** Home Assistant, and Bitfocus Companion mode, which makes the tablet a Companion button panel.
- **Plugins made for the Elgato Stream Deck:** only two of Elgato's sample plugins have been tried.

## Known issues

- **Uninstalling doesn't remove your setup.** Your pairings, profiles and settings, passwords included, stay in `%APPDATA%\perritodeck\PerritoDeck` even with **Delete the application data** ticked; delete that folder by hand to remove them. Installing a later version first runs this version's uninstaller, which doesn't touch them either, and its "Click OK to kill it" just closes PerritoDeck.
- **Apps run as administrator don't get hotkeys or typed text,** and nothing says so. Start the app normally if you can; for OBS, use the OBS buttons instead of hotkeys ([more](https://perritodeck.dev/guide/troubleshooting.html#admin-apps)).
- **OBS, Home Assistant and Companion settings take effect after a restart.** You set them up in **Settings → Integrations**, and saving there offers **Restart now** ([how](https://perritodeck.dev/guide/integrations.html#setup)).
- **A shared profile can split a command across two keys,** one that types it and one that presses Enter, and importing doesn't warn about that, though it does list every single key that runs a program or types and confirms something. Import only profiles you trust.
- **Look online can offer a plugin made for a newer PerritoDeck.** The catalogue has the latest plugin versions, and a plugin can't yet say which PerritoDeck it needs.
- **On the Fire 7,** switching pages freezes the screen for about half a second, and over Wi-Fi, changes the computer sends by itself (titles, live values, pages) can take up to a second to show.
- **On a phone held sideways,** keys can end up under the camera cutout.

## Getting help

Stuck? See the [troubleshooting guide](https://perritodeck.dev/guide/troubleshooting.html).

To report a bug or ask for a feature or a plugin, [open an issue](https://github.com/perritodeck/perritodeck/issues/new/choose) and pick a form. For a bug, paste what **Settings → Getting help → Copy diagnostics** gives you. It leaves out keys, tokens and passwords, but it shows folder paths, which include your Windows user name, and your tablets' names, so read it before you post.

Report security problems privately: use [Report a vulnerability](https://github.com/perritodeck/perritodeck/security/advisories/new), or email dev@perritodeck.dev with "SECURITY" in the subject ([SECURITY.md](https://github.com/perritodeck/perritodeck/blob/main/SECURITY.md)).
